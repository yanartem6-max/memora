                            QUICK START (4 STEPS)

STEP 1: Create GitHub Repository
───────────────────────────────
1. Go to https://github.com/new
2. Create repository: "memora"
3. Make it PUBLIC
4. Click "Create repository"
5. Copy the URL shown

Time: 2 minutes


STEP 2: Push Code to GitHub
──────────────────────────
Open PowerShell and run:

  cd d:\MEMORA
  git remote add origin https://github.com/YOUR_USERNAME/memora.git
  git branch -M main
  git push -u origin main

Replace YOUR_USERNAME with your GitHub username.

Time: 1 minute


STEP 3: Deploy on Railway
────────────────────────
1. Go to https://railway.app
2. Click "Create New Project"
3. Select "Deploy from GitHub"
4. Connect GitHub (first time only)
5. Select "memora" repository
6. Click "Deploy"
7. Wait for ✅ "Deployed" status

Time: 5 minutes


STEP 4: Configure & Launch
──────────────────────────
In Railway Dashboard → Variables tab, add:

  TELEGRAM_BOT_TOKEN=<get from @BotFather>
  JWT_SECRET=<use 32 random characters>
  ENCRYPTION_KEY=<use 32 random characters>
  NODE_ENV=production

To get TELEGRAM_BOT_TOKEN:
  - Open Telegram
  - Search for @BotFather
  - Send: /newbot
  - Follow prompts
  - Copy token

Time: 2 minutes

✅ YOUR APP IS NOW LIVE!

Get your URL from Railway Dashboard → Settings → Service Domain
Example: https://memora-production.up.railway.app
