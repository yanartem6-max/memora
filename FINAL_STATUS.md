## 🚀 Quick Start

### Method 1: Automated (Recommended)
```bash
cd d:\MEMORA
bash START.sh              # macOS/Linux
# or
START.bat                  # Windows
```

### Method 2: Manual
```bash
cd d:\MEMORA
npm install
createdb memora
npm run migrate -w backend
cp .env.example .env
# Add TELEGRAM_BOT_TOKEN to .env
npm run dev
```

### Method 3: Docker
```bash
cd d:\MEMORA
docker-compose up
```

**Result**: Opens at http://localhost:3000
