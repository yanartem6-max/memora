## ⏱️ Time to Live: 15 Minutes

Follow these 4 simple steps to launch your app:

### Step 1: Create GitHub Repo (2 min)
```
1. Go to https://github.com/new
2. Create repo: "memora"
3. Make it public
4. Copy the URL
```

### Step 2: Push Code (1 min)
```bash
cd d:\MEMORA

git remote add origin https://github.com/YOUR_USERNAME/memora.git
git branch -M main
git push -u origin main
```

### Step 3: Deploy on Railway (5 min)
```
1. Go to https://railway.app
2. Create New Project
3. Select "Deploy from GitHub"
4. Connect GitHub
5. Select memora repo
6. Click Deploy
7. Wait for ✅ Deployed
```

### Step 4: Configure & Launch (2 min)
In Railway Dashboard → Variables:
```
TELEGRAM_BOT_TOKEN=<from @BotFather>
JWT_SECRET=<32 chars>
ENCRYPTION_KEY=<32 chars>
NODE_ENV=production
```

**Get your live URL from Railway Dashboard!**
