## 📞 Troubleshooting

### "Port 3000 already in use"
Change port in `frontend/.env.local`:
```
PORT=3001
```

### "Blank page"
Hard refresh: Ctrl+Shift+R (or Cmd+Shift+R on Mac)

### "Styling issues"
Clear browser cache or use private window
