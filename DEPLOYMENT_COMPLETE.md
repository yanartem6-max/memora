## 🚀 Deployment Quick Start

### Step 1: Push to GitHub (1 minute)
```bash
cd d:\MEMORA
git remote add origin https://github.com/YOUR_USERNAME/memora.git
git branch -M main
git push -u origin main
```

### Step 2: Deploy on Railway (5 minutes)
```
1. Go to https://railway.app
2. Create New Project
3. Deploy from GitHub
4. Select memora repository
5. Click Deploy
```

### Step 3: Configure Variables (2 minutes)
```
In Railway Dashboard → Variables:
- TELEGRAM_BOT_TOKEN
- JWT_SECRET
- ENCRYPTION_KEY
- NODE_ENV=production
```

### Step 4: Get Live URL (30 seconds)
```
Railway Dashboard → Settings → Service Domain
Your URL: https://memora-production.up.railway.app
```

**Total Time to Live: ~10 minutes** ⏱️
